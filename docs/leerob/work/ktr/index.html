K*** (한***)

공공기관

시험·연구 데이터 처리를 위한 클러스터를 표준화된 방식으로 신속히 배포해야 했습니다.

netplan 기반 네트워크 구성과 전용 배포 스크립트를 작성해 클러스터 배포 과정을 자동화했습니다. 같은 스크립트 세트를 여러 환경(제어망/통신망)에 반복 적용할 수 있도록 구성해 배포 표준화를 확보했습니다.

구축 이슈를 신속히 조치하며 표준화된 배포 절차를 확보했습니다.

Built with OpenStack, Ansible, and a lot of troubleshooting logs.
