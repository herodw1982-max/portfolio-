한*** · 빅데이터 결합안심 시스템

설계구축 공공기관

배경

대용량 정형·비정형 데이터를 안전하게 결합·분석할 격리된 프라이빗 클라우드 인프라가 필요했습니다.

수행 내용

OpenStack 프라이빗 클라우드를 구축하고 Glance/Cinder 스토리지를 구성했으며, 배포 자동화 도구를 적용했습니다. 운영 과정에서는 스토리지 드라이버 호환성, 이미지 저장 권한, 네트워크 접근 제한 등 실제 배포 환경에서만 드러나는 이슈들을 하나씩 해결했습니다.

주요 이슈 대응
이슈원인조치
PureStorage 드라이버 미지원Cinder venv에 벤더 드라이버 패키지 부재wheel 패키지 배포서버 등록 후 venv에 설치, cinder-volume 재기동
Netapp 스토리지 이미지 저장 실패glance-api privsep 헬퍼가 venv 실행 경로에 대한 권한 없음rootwrap.conf exec_dirs에 glance venv bin 경로 추가
Compute 노드 배포 시 패키지 설치 실패Compute → Controller 저장소 간 방화벽 포트 차단배포 노드 경유로 임시 우회 설치 후 완료 시 원복

성과

배포 이슈 및 운영 조치 대응 체계를 확립해 안정적인 서비스 운영을 지원했습니다.

Built with OpenStack, Ansible, and a lot of troubleshooting logs.
