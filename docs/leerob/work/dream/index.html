민간기업

운영 중인 OpenStack 인프라에서 특정 Compute 노드로 인스턴스가 배치되지 않는 현상이 발생했습니다.

인스턴스 배치 편중 이슈
구분내용
현상특정 Compute 노드로 인스턴스 할당이 되지 않음. 다른 노드를 disable하면 정상 동작
원인Nova filter_scheduler가 가중치 계산 시 해당 노드를 우선순위에서 지속적으로 배제
조치scheduler 재시작 + shuffle_best_same_weighed_hosts, num_instances_weight_multiplier 파라미터 적용으로 분산 배치 유도
영향도Controller 데몬 재기동만 필요해 서비스 영향 없음

이와 함께 MariaDB 메모리·쿼리 사용량을 분석해 성능 조회 체계를 구성했습니다. 자세한 스택은 보유 기술에서 확인할 수 있습니다.

Built with OpenStack, Ansible, and a lot of troubleshooting logs.
