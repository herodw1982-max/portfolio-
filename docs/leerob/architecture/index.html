Version Migration

OpenStack 릴리스를 지속적으로 추적하며 Antelope → Caracal → Epoxy 순으로 버전별 아키텍처를 설계·구축하고, 버전별 오프라인 패키지 저장소(repo)를 구성해 폐쇄망 환경에서도 동일하게 배포할 수 있도록 만들었습니다.

OpenStack 릴리스별 주요 버전
구분AntelopeCaracalEpoxy (2026)
OSUbuntu 22.04, Kernel 5.15.0-87Ubuntu 22.04, Kernel 5.15.0-131Ubuntu 24.04.4 LTS (noble)
MariaDB10.11.210.11.6-
RabbitMQ3.11.103.13.7-
OSA Release--31.1.2

Caracal 업그레이드 중에는 Apache MPM 모듈 미로드, nova-scheduler의 AvailabilityZoneFilter 누락 등을 조치했고, Epoxy 전환 시에는 APT/PyPI/Git 오프라인 저장소 구조를 릴리스별로 분리(/opt/osa/pkg/repo/<release>/)해 Caracal·Epoxy 환경을 동시에 운영할 수 있도록 설계했습니다.

Built with OpenStack, Ansible, and a lot of troubleshooting logs.
