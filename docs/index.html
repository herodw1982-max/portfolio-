Architecture

배포 아키텍처 구성도

NPD Maker는 단일 배포 도구로 Standard(분산형)와 HCI(초융합형) 두 가지 토폴로지를 지원합니다.

Deployer 토폴로지 분기 (Standard / HCI) HA / 장애복구 레이어

Bare Metal 또는 VM 기반으로 Docker 컨테이너화된 OSA 배포 구조를 커스텀. 오프라인(폐쇄망) 설치를 위한 로컬 레포지토리를 함께 구성합니다.

Highlights

핵심 성과

숫자와 실증 테스트로 확인된 결과 위주로 정리했습니다.

인스턴스 HA 장애 복구 실증

Masakari 기반 Instance HA를 배포해 VM 장애 발생 1초 이내 감지 → 자동 재기동, 호스트 장애 시 evacuate 성공까지 실제 장애 시나리오로 검증했습니다.

성능 튜닝 표준화

Nova/Neutron/Galera/RabbitMQ 등 30개 이상 파라미터를 역할별(Controller/Compute/Storage)로 표준화하고, 튜닝 전/후 자동 벤치마크 파이프라인을 구축했습니다.

배포 자동화 솔루션 고도화

Docker 기반 배포 도구를 v1.1 → v2.3까지 지속 개발하고, Antelope → Caracal 버전 마이그레이션을 완료했습니다.

실환경 구축·운영

공공기관 2곳, 민간기업 1곳, PoC 1건 등 4개 고객사 환경에 프라이빗 클라우드를 직접 구축하고 운영 이슈를 조치했습니다.
