03.

Architecture

NPD Maker는 단일 배포 도구로 Standard(분산형)와 HCI(초융합형) 두 가지 토폴로지를 지원합니다.

Deployer / HA 레이어 토폴로지 분기 (Standard / HCI)

Bare Metal 또는 VM 기반으로 Docker 컨테이너화된 OSA 배포 구조를 커스텀. 오프라인(폐쇄망) 설치를 위한 로컬 레포지토리를 함께 구성합니다.

Standard vs HCI 아키텍처 비교
구분Standard (분산형)HCI (초융합형)
노드 구성Controller/Compute/Storage 분리Compute+Storage 단일 노드 통합
적합 규모중대형, 확장성 우선소규모, 엣지/PoC
스토리지전용 Ceph 노드 클러스터Compute 노드 내 Ceph OSD
확장 방식계층별 개별 스케일아웃Converged 노드 단위 스케일아웃
Masakari Instance HA 실증 테스트 환경 (Kolla-Ansible, Rocky 9)
